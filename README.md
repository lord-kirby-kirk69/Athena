## Installation

### Windows

1. Download the `.exe` or `.msi` installer from the Releases section.
2. Open the downloaded file.
3. Follow the installation instructions.
4. Launch Athena AI.

### Linux

1. Download the available `.AppImage` or `.deb` file.
2. For an AppImage, grant execute permission if needed:

   ```bash
   chmod +x Athena*.AppImage
   ```

3. Run the AppImage or install the `.deb` package using your distribution's package manager.

2. Open the disk image.

Make sure you download a build compatible with your Mac's processor. Intel and Apple Silicon Macs may require different builds.

## Getting a Free Google Gemini API Key

Athena AI can use Google's Gemini models with your own API key. Follow these steps to get started.

1. Open [Google AI Studio](https://aistudio.google.com/apikey) and sign in with your Google account.
2. Navigate to the **API Keys** section.
3. Click **Create API key** and select an existing Google Cloud project or create a new one.
4. Copy your generated API key.
5. Open Athena AI, go to the model or provider settings, select **Google Gemini**, and paste your key into the API key field.
6. Save your settings and start chatting.

### Important Notes

- Google offers a free Gemini API usage tier for eligible models and usage, subject to its current quotas and terms. **Free access is not unlimited**, and availability can vary.
- Some models or higher usage levels may require billing to be enabled.
- Keep your API key private. Never post it publicly or share it with others.
- API usage is subject to Google's current rate limits, pricing, and terms.

**Official guide:** [Gemini API Keys Documentation](https://ai.google.dev/gemini-api/docs/api-key)

## Troubleshooting

**The installer will not open**
- Check that you downloaded the correct installer for your operating system and processor.
- Download the file again if it appears incomplete.
- Your operating system may block applications that are not signed or notarized.

**The AI is not responding**
- Check your internet connection if you use an online provider.
- Verify your model and provider settings.
- Check your API credentials, account limits, and provider availability.

**The application is incompatible**
- Check the installer filename and architecture.
- Download a compatible build from the Releases section if one is available.
